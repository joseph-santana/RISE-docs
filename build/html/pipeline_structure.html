Pipeline Structure

There are currently 2 working versions of the RISE pipeline:

Stack then Sub

Stacks single-epoch Roman L2 images, then runs these stacked image products as science inputs into RAPID.

The current Stack then Sub scheme contains /rapid/ and /rise/ directories. The /rise/ directory contains all the RISE products, which can be found here, and the /rapid/ directory contains all the RAPID products, which can be found here.

There is also an /sextractor_outputs/ directory which contains sextractor outputs for SFFT and ZOGY differenced products. This directory is generated by another analysis pipeline separate from the RISE pipeline, though the plan is to implement this analysis pipeline into the RISE pipeline.

Sub then Stack

Performs single-epoch RAPID subtraction on multiple science images, then stacks the differenced RAPID products.

The current Stack then Sub scheme contains multiple epoch directories, epoch{#}, which each contain /rapid/ and /rise/ directories, and an /awaicgen_outputs/ directory.

The /rise/ directory contains all the RISE products, which can be found here, and the /rapid/ directory contains all the RAPID products, which can be found here.

The /awaicgen_outputs/ directory contains stacked products such as a coverage map, an uncertainty image, and the science image.
